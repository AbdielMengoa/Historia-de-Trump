HISPANIDAD - PAGINA WEB

Contenido:

- css/estilos.css

Características:
- HTML5 semántico
- Diseño responsive
- Sin class="" en HTML
- Sin selectores de clase en CSS
- Sin Flexbox
- Sin CSS Grid
- Sin JavaScript
- Galería de imágenes
- Video de YouTube integrado mediante iframe
- Paleta azul, blanca y roja

Uso:
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html en el navegador.

El video utiliza YouTube, por lo que requiere conexión a Internet.
